# Classic theme with developer-controlled layout

The frozen four-page NOIR design will use a classic PHP theme with editable WordPress content and developer-controlled layout. A block theme with Site Editor access was considered, but template, header, and footer layout editing is not required and would introduce additional ways to drift from the frozen composition. Shared content will have one authoritative source; this decision does not establish a storage schema or approve custom post types.

Presentation will use maintainable theme CSS with custom properties and small vanilla JavaScript files. Deployable assets are included in project source; ordinary styling changes do not require a Node build, though development checks may use tooling.
