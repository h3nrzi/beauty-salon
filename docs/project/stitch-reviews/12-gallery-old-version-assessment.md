# Stitch Review 12 — Gallery old-version assessment

**Reviewed:** 2026-10-10  
**Source:** `stitch_salon_visual_baseline (12).zip`  
**Package SHA-256:** `8d2ff2a62a019b769d1c54e8ab6a8e7e997736dde4a39475f0d26ccc13ea28b2`  
**Purpose:** Review the existing Gallery page before writing the refinement prompt.

## Current page structure

The old Gallery page already has a strong desktop portfolio structure:

- public header/navigation;
- editorial page intro;
- category/filter chips;
- six image-led cards in a 3-column × 2-row grid;
- image + category + title + short description;
- specialist attribution;
- technique/detail metadata;
- per-card CTA;
- lower informational/guidance blocks;
- public footer.

The visual density is good and should be preserved.

## What should be preserved

### 1. Six-item editorial grid

The strongest part of the current page is the image-led catalog.

Preserve:

- six visible gallery items;
- balanced 3-column desktop composition;
- large image emphasis;
- restrained supporting metadata;
- category chips;
- clear page title / intro.

Do not turn Gallery into a sparse hero page or a social feed.

### 2. Category discovery

The current filter row is useful.

Keep a restrained set of categories, but use product-neutral beauty categories.

Examples:

- همه نمونه‌ها
- مو و استایل
- رنگ و لایت
- ناخن
- مژه و ابرو
- آرایش
- فضای سالن, only if useful as a small secondary category

Do not use `اسپا` as a positioning/category concept.

### 3. Specialist attribution

Showing who performed the work can be useful.

Keep specialist attribution simple and neutral.

Do not use ratings, senior/master hierarchy, certificates or “international specialist” claims.

## What should improve

### 1. The page contains many unsupported claims

Current copy includes:

- `عکاسی بدون روتوش اغراق‌آمیز`;
- `متخصصان بین‌المللی`;
- `مواد بدون آسیب`;
- `بدون تخریب فولیکول`;
- `شفافیت پایدار`;
- `ارگانیک`;
- `اکسیژن‌رسانی سلولی`;
- `ماساژ لنفاوی`;
- `تقویت کلاژن`;
- `بدون فیلترهای فریبنده`.

These claims are unnecessary for a portfolio page and should be removed.

Use neutral visual descriptions of the work only.

### 2. Clinical / therapeutic / spa language is too strong

Current examples include:

- `فیشیال آبرسانی ارگانیک`;
- `ماساژ لنفاوی`;
- `ناخن و اسپا`;
- `اسپا سر و احیای آرامش`;
- `تست حساسیت`;
- physiological/health wording.

The refined Gallery should remain a beauty portfolio, not a spa/clinic/treatment page.

### 3. “Technique” metadata is over-detailed and marketing-heavy

Current cards expose highly specific technique/formula language such as:

- proprietary/product-style technique names;
- material/process jargon;
- branded treatment/formula wording.

The portfolio page can show concise, neutral metadata if useful, for example:

- `دسته‌بندی`
- `متخصص`
- a short `جزئیات اجرا` phrase.

Do not turn cards into technical treatment records.

### 4. CTA language is inconsistent with Gallery purpose

Current cards use:

- `رزرو مشاوره`

The product does not define consultation as a required or standalone workflow.

Prefer:

- `رزرو نوبت`
- or `مشاهده خدمت مرتبط`

Do not introduce a separate consultation product.

### 5. The lower “smart color/form selection” section is out of scope

Current page includes:

- face/bone-structure analysis;
- skin-tone matching;
- digital drafts;
- sensitivity testing;
- personalized home-care routines;
- dedicated sample/material booklet;
- consultation request.

This creates a new consultation/analysis workflow and should be removed.

Replace it with a restrained, product-grounded closing section such as:

- explore Services;
- choose a specialist;
- start Booking.

### 6. Privacy/media claims are too specific

The page says:

- all images have full customer consent;
- captured in a dedicated light room;
- no deceptive filters.

Production media rights are important, but Stitch must not freeze unsupported legal/media claims.

Use a neutral portfolio presentation.

Media-rights verification belongs to production acceptance, not Gallery marketing copy.

### 7. Footer contains unsupported business facts

Current footer contains:

- north-Tehran prestige wording;
- exact Zafaraniyeh address;
- exact phone;
- exact opening hours;
- `خدمات تخصصی`;
- `رزرو آنلاین وقت`.

Use the neutral frozen public-footer pattern from Home/Services/Specialists.

## Refinement target

The new Gallery page should combine:

- **old Gallery** for six-item image density / category structure;
- **frozen Home** for editorial public-page visual language;
- **frozen Services** for consistent header/footer/CTA grammar.

The result should feel like a curated visual portfolio of salon work, not a clinic, social feed, consultation funnel, or technical treatment catalog.
