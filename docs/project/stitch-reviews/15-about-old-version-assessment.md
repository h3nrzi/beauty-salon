# Stitch Review 15 — About old-version assessment

**Reviewed:** 2026-10-10
**Source:** `stitch_salon_visual_baseline (16).zip`
**Purpose:** Review the existing About page before refinement.

## Preserve

The old About page has a useful editorial desktop structure:

- public header/navigation
- editorial intro
- long-form brand-story section
- salon-atmosphere imagery
- visual highlight/stat cards
- four values cards
- team section
- closing CTA
- public footer

Preserve the story-led rhythm, generous imagery, values section, team section and overall page depth.

## Improve

Remove or neutralize:

- exact founding year and business milestones
- Zafaraniyeh / north-Tehran prestige positioning
- exclusive-mansion / exclusive-suite / theatrical luxury language
- invented numeric claims such as 100% single-client appointments and 12 senior specialists
- health/clinical claims about hair/skin
- organic/material/certification claims
- international academy / Milan / Paris / Dubai claims
- senior/master/expert hierarchy
- absolute no-delay guarantees
- mandatory 30-minute consultation before every service
- consultation as a standalone CTA/workflow
- exact fictional address, phone and opening hours

## Specific copy problems

The old page currently includes concepts such as:

- `پناهگاهی آرام و اختصاصی`
- `مراسمی انحصاری`
- `متخصص ارشد`
- `استادان هنر زیبایی`
- `فرمولاسیون‌های ارگانیک معتبر جهانی`
- `گواهینامه‌های رسمی آکادمی‌های معتبر اروپایی`
- `مشاوره تخصصی ۳۰ دقیقه‌ای پیش از هر خدمت`

These should not survive refinement.

## Refinement target

The refined About should combine:

- old About for editorial structure and depth
- frozen Home for public visual language
- frozen Gallery for image treatment
- frozen Specialists for neutral team wording

The result should feel calm, credible and editorial — not like a spa, clinic, luxury retreat, certification showcase or consultation funnel.

If visual stat/highlight cards are retained, replace invented numbers with non-numeric product/brand highlights such as:

- `اطلاعات روشن خدمات`
- `انتخاب متخصص`
- `رزرو و مدیریت نوبت`

Product Definition remains authoritative.
