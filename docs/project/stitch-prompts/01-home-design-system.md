# Stitch Prompt 01 — Home + initial design system

Use this prompt to start the first visual exploration in Stitch.

---

Design the **Home page and initial visual system** for a Persian/RTL women's beauty salon brand named **«آرا»**.

This is not a generic salon landing page. It is the public entry point to a real beauty-booking product.

## Product context

آرا is a single women's beauty salon.

The website combines:
- salon discovery and trust-building;
- services and specialist discovery;
- visual portfolio/gallery;
- a real appointment-booking flow;
- authenticated appointment management.

For this first Stitch pass, focus on the **Home page and reusable visual language** only. Do not invent new product capabilities.

## Language and direction

- Persian language.
- RTL layout designed natively for RTL, not mirrored from an English/LTR template.
- Use realistic Persian placeholder copy.
- Avoid lorem ipsum.
- Use Persian numerals where appropriate in visible mock content.

## Visual direction: Soft Editorial

Create a look that feels:
- calm;
- feminine;
- modern;
- premium;
- warm;
- editorial;
- trustworthy.

Avoid:
- generic pink-and-gold beauty-salon styling;
- ultra-luxury black/gold clichés;
- ornamental overload;
- glassmorphism-heavy UI;
- dense SaaS card grids;
- excessively rounded components;
- fashion-editorial styling that hurts booking clarity.

Preferred visual foundation:
- warm ivory / off-white backgrounds;
- light taupe / stone neutrals;
- one restrained warm accent such as muted terracotta or rose-brown;
- charcoal or deep warm-gray text;
- generous whitespace;
- thin/dividing lines used sparingly;
- subtle borders/shadows;
- elegant Persian display typography for headings paired with highly readable Persian UI typography.

Photography should feel natural and refined:
- soft daylight;
- close-up beauty details;
- real salon atmosphere;
- hair, nails, skin, tools and human moments;
- avoid overly retouched glamour-stock imagery.

## Home page goals

The page must help a first-time customer quickly understand:
1. what آرا is;
2. what services it offers;
3. why it is trustworthy;
4. who the specialists are;
5. what the salon's work looks like;
6. how to start booking.

## Required Home content

Create a coherent Home page including:

### Header
- brand wordmark: «آرا»
- primary navigation to خدمات، متخصص‌ها، گالری، درباره ما، تماس
- a clear «رزرو وقت» CTA
- access to «وقت‌های من»
- responsive mobile navigation

### Hero
- strong Persian headline that positions آرا as a modern women's beauty salon
- short supporting copy
- primary CTA: «رزرو وقت»
- secondary discovery CTA such as «مشاهده خدمات»
- one strong editorial image/composition

### Selected services
Show a curated set of representative services with:
- service name;
- short description;
- duration;
- price;
- clear path toward booking.

The cards/rows should establish a reusable service presentation system without becoming visually heavy.

### Selected specialists
Introduce a few specialists with:
- portrait;
- name;
- expertise;
- concise service relationship;
- booking/discovery affordance.

### Trust / benefits section
Communicate meaningful product trust signals such as:
- متخصص‌های حرفه‌ای;
- زمان‌بندی شفاف;
- رزرو ساده;
- فضای حرفه‌ای و آرام.

Do not invent reviews, ratings, awards or unsupported numerical claims.

### Selected gallery
Use an editorial image layout to preview salon work.
It should feel curated, not like a social-media feed.

### Booking bridge / CTA
Create a strong section that transitions from discovery into the real booking experience.
It should make the next step obvious without designing the full Booking flow yet.

### Footer
Include:
- essential navigation;
- contact/address placeholders;
- salon hours placeholders;
- phone/contact path;
- brand mark.

Do not add legal claims or unsupported social links unless clearly presented as placeholders.

## Product constraints to respect

- Booking can include multiple compatible services.
- Customer may choose a specific specialist or “any available specialist”.
- Payment happens at the salon.
- Do not introduce online checkout/deposit UI.
- Do not add marketplace/multiple branches.
- Do not add reviews/ratings, loyalty, CRM, ecommerce, membership plans or app-download promotions.
- Do not design password-based account UI.

## Accessibility and interaction

Target WCAG 2.2 AA for primary interactions.

Show:
- visible focus treatment;
- strong text contrast;
- clear CTA hierarchy;
- readable Persian typography;
- touch-friendly mobile controls;
- semantic-looking navigation/sections;
- layouts that can reflow cleanly.

Avoid relying on color alone for state or meaning.

## Responsive exploration

Show the Home page at:
- a mobile width first;
- a desktop width second.

The mobile version must not feel like a compressed desktop layout.

## Design-system output

From this Home exploration, establish a reusable initial system for:
- colors;
- typography scale;
- spacing rhythm;
- buttons;
- links;
- service cards/rows;
- specialist cards;
- image treatments;
- section headings;
- navigation;
- form/control styling direction for future Booking screens.

Do not define engineering architecture, WordPress structure, APIs, storage, authentication implementation or SMS provider.

## Success criteria

The result should feel like:
**a real Persian premium beauty brand that can naturally extend into a serious booking application**, not a decorative brochure template.

Favor clarity, warmth, editorial hierarchy and trust over visual gimmicks.
