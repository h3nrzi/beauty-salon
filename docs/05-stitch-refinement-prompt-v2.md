# Stitch Refinement Prompt — v2

## Goal

Refine the existing **NOIR Auto Detailing** project.

Do **not** redesign it from scratch.

The current visual system is approved and should remain recognizable:

- obsidian/dark-neutral foundation
- champagne/gold accent
- Syne + Inter typography direction
- sharp rectangular geometry
- hairline borders
- editorial automotive photography
- spacious architectural grid
- high-contrast premium aesthetic

The problem is not the visual identity. The problem is that the current content and UX are too elaborate for this product.

## Global refinement instructions

Keep the current visual quality, but make the website feel like a believable premium auto-detailing studio rather than an ultra-exclusive fictional atelier.

### Simplify language

Use direct, premium, understandable automotive-detailing language.

Reduce or remove repeated terminology such as:

- atelier
- commission
- allocation
- registry
- archival
- clinical protocol
- master protocol

Do not remove all personality, but prioritize clarity over theatrical luxury language.

### Reduce information density

Reduce total visible copy and secondary metadata by approximately 25–35%.

Preserve whitespace.

Keep the strongest labels and proof points only.

Avoid filling every section with technical metrics, codes, status chips, certifications or operational statistics.

### Do not invent business claims

Avoid highly specific certifications, capacities, environmental measurements, customer counts, OEM claims or operational statistics unless they are clearly neutral placeholders.

The design must remain credible with ordinary real business content later.

### Preserve the four-page scope

Do not add new pages.

Keep:

1. Home
2. Services
3. Gallery
4. Contact / Appointment Request

---

## Home refinement

Keep the current visual structure and editorial direction.

Simplify the copy.

The visitor should immediately understand:

- premium auto detailing
- what services are available
- why the work is trustworthy
- how to request an appointment

Keep:

- strong hero
- Request Appointment CTA
- View Services CTA
- featured services
- selected work / before-after
- concise trust section
- testimonials
- final CTA

Reduce decorative technical metadata and fictional operational claims.

## Services refinement

Keep the alternating editorial service layout, but make the page significantly easier to scan.

Use these plain service names prominently:

- Exterior Detail
- Interior Detail
- Full Detail
- Paint Correction
- Ceramic Coating

For each service, keep:

- short description
- concise included-items list
- optional starting price
- approximate duration
- Request Appointment / Book Service CTA

Avoid excessively technical naming and long protocol descriptions.

Keep the process and FAQ sections, but shorten them.

---

## Gallery refinement

Preserve the current gallery direction.

This page is visually successful.

Keep:

- photography-first composition
- before/after interaction
- category/filter concept
- concise case-study information

Shorten fictional project descriptions and avoid relying on invented technical measurements to make the cards feel complete.

The layout must still work when WordPress receives normal project titles, short captions and images.

---

## Contact / Appointment Request refinement

Simplify this page significantly.

This is a lead-generation form, not an operational intake system.

Use this form scope only:

- Name
- Phone
- Email (optional)
- Vehicle make/model
- Service of interest
- Preferred date
- Message / notes

Remove:

- vehicle-condition grading
- transport/logistics requests
- complex intake classifications
- unnecessary operational options

Keep the message clear:

**Submitting the form requests an appointment. The studio will contact the customer to confirm availability and details.**

Use normal premium business terminology such as:

- Contact
- Appointment Request
- Studio
- Opening Hours
- Location

Avoid framing the experience as a commission/allocation dossier.

---

## Responsive behavior

Preserve the responsive design quality.

Check that mobile:

- has an obvious primary CTA
- uses comfortable type sizes
- does not become overly dense
- keeps service cards easy to scan
- keeps the gallery useful
- keeps the simplified form easy to complete
- has no horizontal overflow

Do not optimize specifically for PHP or WordPress.

However, keep visual patterns consistent across pages:

- same header/footer system
- same buttons
- same form controls
- same typography
- same spacing
- same colors
- same card patterns

Preserve and update the shared DESIGN.md so it accurately describes the final design system.

This is a refinement pass, not a redesign.
